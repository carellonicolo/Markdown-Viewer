# Novità

## 2.3 — 2026-11-12

- Vista HTML: il selettore Anteprima | HTML nella barra in alto (o Vista → Mostra codice HTML, ⌥⌘U)
  mostra il codice HTML generato, colorato e con i numeri di riga, aggiornato mentre scrivi.
- Pulsante Copia HTML per incollare il codice in un sito o in una piattaforma come Moodle.
- Nella vista HTML l'indice porta alla riga in cui inizia ogni titolo.

## 2.2 — 2026-11-12

- Esportazione in HTML (File → Esporta come HTML…, ⇧⌘H, o pulsante Esporta): una sola pagina che si
  apre in qualsiasi browser, con immagini, formule e diagrammi incorporati.
- Nella barra in alto il pulsante Esporta offre PDF e HTML.

## 2.1 — 2026-11-06

- Numeri di riga nell'editor, con la riga corrente evidenziata.
- L'indice dei titoli si adatta alla larghezza della barra laterale (prima i titoli lunghi restavano troncati).

## 2.0 — 2026-11-06

Prima versione pubblica.

- Lettura dei file Markdown formattati, aggiornati da soli quando il file cambia.
- Editor affiancato all'anteprima, aggiornata mentre scrivi (⌘E), con salvataggio (⌘S).
- Indice dei titoli, ricerca nel documento, tre temi (Standard, Libro, Compatto), modalità scura.
- Evidenziazione del codice, formule matematiche (KaTeX) e diagrammi Mermaid.
- Esportazione in PDF e stampa.
- Anteprima con la barra spaziatrice nel Finder (Quick Look).
- Ricorda dove eri arrivato a leggere in ogni file.
